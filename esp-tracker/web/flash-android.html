Flash Tracker — Android

Flash the tracker firmware from your Android phone via USB OTG. No computer needed.

What you need

  • Android phone with USB OTG support
  • USB OTG cable (USB-C or Micro-USB to USB-A female)
  • Termux — install from F-Droid (NOT Play Store — outdated version)
  • Termux:USB — install from F-Droid
Important: Install Termux from F-Droid, not Google Play. The Play Store version is outdated and may not work with USB.

Step 1: Install Termux

  1. Install Termux from F-Droid
  2. Install Termux:USB from F-Droid
  3. Open Termux — you'll see a terminal prompt

Step 2: Download the flash script

Tap the button below to download the flash script, then open it in Termux:

Download flash.sh
Tip: If the download doesn't start, long-press the link and choose "Save link" or "Download link".

After downloading, run it in Termux:

cd ~/Downloads
bash flash.sh

Step 3: Connect the tracker

  1. Plug the tracker into your phone using the USB OTG cable
  2. When Android asks "Allow Termux to access USB?", tap OK
  3. If no prompt appears, open Termux:USB and grant permission there
  4. The script will detect the ESP32 and flash automatically
Tip: If flashing doesn't start, hold the BOOT button on the tracker while the script tries to connect.

Step 4: Configure the tracker

  1. After flashing, hold the SOS button for 2+ seconds until the LED blinks blue
  2. Connect your phone to WiFi network "Tracker-Setup" (open, no password)
  3. Open http://192.168.4.1 in your browser
  4. Enter SOS number, scanner number, and WiFi credentials
  5. Tap "Save & reboot"

Troubleshooting

ProblemFix
No ESP32 found on USBCheck OTG cable is data-capable, not charge-only. Try a different cable.
USB permission not grantedOpen Termux:USB app, grant permission to Termux. Re-run script.
Flashing fails / timeoutHold BOOT button on tracker while script starts. Try 460800 baud.
Termux not from F-DroidUninstall Play Store version, install from F-Droid instead.

Manual flash (copy-paste)

If the download button doesn't work, paste this entire block into Termux:

pkg update -y && pkg install -y python curl
pip install esptool
curl -L -o ~/firmware.bin "https://web-ten-beta-17.vercel.app/firmware/firmware.bin"
echo "Now plug in the tracker via USB OTG..."
echo "Waiting 5s for USB permission prompt..."
sleep 5
for p in /dev/ttyUSB* /dev/ttyACM*; do
  [ -e "$p" ] && python3 -m esptool --chip esp32 --port "$p" --baud 460800 write_flash -z 0x0 ~/firmware.bin && exit 0
done
echo "No ESP32 found. Check cable and USB permission."
